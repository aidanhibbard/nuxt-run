# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| 0.x     | :x:                |

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Report security issues privately via [GitHub Security Advisories](https://github.com/aidanhibbard/nuxt-run/security/advisories/new) (preferred) or by emailing the repository owner through their GitHub profile contact options.

Include:

- A description of the issue and its impact
- Steps to reproduce or a proof of concept
- Affected versions and configuration (Nuxt version, deployment setup, etc.)

You can expect an initial response within a reasonable timeframe. We will work with you on a fix and coordinated disclosure when appropriate.

## Scope

This policy covers the **nuxt-run** package and its published runtime (module and generated script entries). Issues in downstream dependencies (Nuxt, Nitro, Rollup, etc.) should be reported to those projects when they are the root cause.
